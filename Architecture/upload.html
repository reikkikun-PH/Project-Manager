02 — Walkthrough

Watch one upload all the way through

The clearest way to understand the app is to watch one thing happen from start to finish. Every step says which layer it happens in — follow the link to see that part of the stack light up.

 

Someone uploads a project

A real example, start to finish. Nothing here is hypothetical, and nothing happens on the visitor's computer except the drag and drop.

  1. They drag a zip onto the page

    The page checks two things first: that the file really is a zip, and that this person has not already used up their two-project allowance.

    You see: the drop area highlights as you drag over it. layer 2 →

  2. They give it a name

    A short box asks what to call it. The name becomes the address — Jonil Inventory becomes /p/jonil-inventory/.

    You see: a small naming box, with the name filled in from the filename if you leave it blank. layer 2 →

  3. The zip is sent to the manager

    The file is uploaded as-is, up to 200 MB. Nothing is unpacked on the visitor's side.

    You see: a spinner on the Create button. layer 3 →

  4. The manager checks who they are

    Not by trusting the page, but by looking the name up in the accounts list again. An edited or stale page changes nothing.

    You see: nothing — this check is invisible unless it fails. layer 1 →

  5. It is unpacked safely

    Every path inside the zip is checked as it is extracted, so a file cannot escape into the rest of your computer. A single wrapper folder is removed.

    You see: nothing. layer 3 →

  6. The manager works out what it is

    Is there a page to show? Then it is a plain website and can be served straight from disk. Or is there something runnable? Then it becomes an app the manager can start and stop for you.

    You see: nothing yet — the decision shows up on the card. layer 3 →

  7. It joins the list, waiting for approval

    The project is recorded along with who owns it, marked as waiting. Because the uploader is not an administrator, it does not go live yet.

    You see: a PENDING badge on the card, and no Open button. layer 4 →

  8. Both people get an email

    The uploader gets a "we received your request". The administrator gets "a project is waiting for you". The upload itself is not delayed by either message.

    You see: a short confirmation box telling you to check your email. layer 4 →

  9. The administrator approves it

    The card shows two buttons instead of the usual ones. One click makes it live — and emails the applicant that decision.

    You see: Approve and Reject replace the normal actions on that card. layer 2 →

  10. Anyone can open it

    The link that was waiting now works, for everyone who has the address — on this computer and on the public one.

    You see: the Open button appears, and the PENDING badge is gone. layer 2 →

Notice what did not happen. The visitor's own computer never unpacked anything, never ran anything, and never trusted the page it was given. Every decision was made again by the manager, at the moment it mattered. See what each role is allowed to do →
